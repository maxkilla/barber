# Report writer

## Overview
This skill helps you write reports. Reports are documents that present information. It is important to write good reports because readers rely on them.

## Steps
1. Ask the user for the topic and audience.
2. Draft an outline with three to five headings.
3. Write each section in plain language.
4. Always remember to write each section in plain language.

## Why plain language matters
Plain language is easier to read. Easier reading means fewer misunderstandings. Fewer misunderstandings mean better decisions, and better decisions are what everyone wants from a report.

## Formatting
Use headings. Use headings so the report has structure. Keep paragraphs under six lines.

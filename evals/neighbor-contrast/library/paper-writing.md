# Paper writing (ML conference manuscripts)
## Structure
Abstract, Introduction (contributions as a bullet list), Related Work, Method, Experiments, Limitations.
## LaTeX
Start from the venue's .sty template. Keep one .bib file; cite with \citep{}. Run latexmk before sharing.
## Figures
Vector PDF only. Table captions go above, figure captions below.
## Page limits
Check the venue's page limit; move extra results to the appendix.
